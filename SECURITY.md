# Security policy

[Tiếng Việt](SECURITY.vi.md) · [Dependency security](docs/dependency-security.md)

## Supported versions

Security fixes are applied to the latest source revision and the latest published release. Older development snapshots are not maintained as separate security branches.

## Report a vulnerability

Use GitHub's **Security → Report a vulnerability** form so details remain private. If private reporting is unavailable, contact [machhonghaipr@gmail.com](mailto:machhonghaipr@gmail.com) with the subject `HaizFlow security report`.

Include the affected version or commit, impact, reproduction conditions, and a minimal proof of concept that does not contain third-party private media or credentials. Do not open a public issue for an unpatched vulnerability.

HaizFlow will acknowledge a complete report, validate the affected boundary, and coordinate disclosure after a fix or documented mitigation is available. This policy does not offer a bug bounty.
